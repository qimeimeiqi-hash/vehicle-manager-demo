# 車両管理システム — Webデモ版

中古車輸出業務向けに開発した**オフライン・デスクトップアプリ（Electron）**を、そのままブラウザで操作できるようにしたデモ版です。

- **デモ**：https://qimeimeiqi-hash.github.io/vehicle-manager-demo/
- このリポジトリにはビルド済みのデモのみを置いています（ソースコードは非公開）。
- 表示されるデータ・会社名（サンプル商事株式会社）・顧客名はすべて**架空のサンプル**です。

## デモ用アカウント

| ユーザー名 | パスワード | 役割 |
|---|---|---|
| admin | admin | 管理者（すべての操作が可能） |
| operator | operator | オペレーター（削除・ユーザー管理以外） |
| Savanna Auto | visitor | 訪問者（自分の車両のみ閲覧・編集不可） |

編集内容はご自身のブラウザ（IndexedDB）にのみ保存され、外部には送信されません。画面下の「デモ版」から初期データに戻せます。

## 主な機能

- 価格管理表・車両/船積情報・船積書類・ユーザー管理の4画面（番号で3つの業務テーブルを1:1:1で連動）
- 表のセルを直接編集し、自動保存（保存ボタンなし）。総額は仕入価格＋陸送代で自動計算
- 検索エリア、表頭のフィルター（候補の絞り込み検索付き）、ページ番号ジャンプ
- 写真・出荷票（複数ファイル）・船積書類PDFのアップロード／プレビュー
- ロール別の権限制御（管理者 / オペレーター / 訪問者）。訪問者は自分の顧客名の車両のみ閲覧可
- 日本語 / 中文 / English の3言語切り替え

## 技術構成

- **本体**：Electron + React + TypeScript + Vite + Tailwind CSS + SQLite（better-sqlite3）、TanStack Table（仮想スクロール）、react-i18next
- **Webデモ**：デスクトップ版のSQL・リポジトリ・権限チェック・画面コードをそのまま再利用し、SQLiteをsql.js（WebAssembly）に、Electronのプロセス間通信をブラウザ内の仕組みに置き換えて動作
- **テスト**：Vitest（単体・コンポーネント）、Playwright（Electron実機／Webデモのエンドツーエンド）

> デスクトップ版にある「ファイルをOSのクリップボードへコピー」は、ブラウザの制約によりデモ版ではダウンロードになります。
